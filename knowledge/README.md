# Dossier candidat

Déposez ici vos documents (`.md`, `.txt`, `.pdf`) : CV, fiches projets, notes techniques, offre d'emploi.
Ils sont lus au démarrage (ou via « + Ajouter un document » dans l'interface).

Ces fichiers sont personnels : ils sont exclus de Git par le `.gitignore`.

Conseil : une fiche par projet, avec contexte, votre rôle, la stack, des chiffres concrets et les difficultés
rencontrées. Claude s'appuie dessus pour proposer des exemples réels et n'invente jamais d'expérience.
Voir `exemple_fiche_projet.md`.
